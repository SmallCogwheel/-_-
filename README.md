# ☕ 카페인 계산기

사용자의 음료 섭취량과 체중을 기반으로 카페인 섭취량과 권장량을 계산해주는 웹 애플리케이션입니다.

## 📌 프로젝트 소개
HTML, CSS, JavaScript로 만든 간단한 카페인 계산기입니다.  
사용자의 조건(성인 / 청소년 / 임산부 / 체중 / 섭취량)에 따라 카페인을 계산하고 권장량 대비 비율을 시각화합니다.

## ⚙️ 주요 기능
- 음료 종류 선택
- 용량(ml) 선택
- 섭취 개수 입력
- 사용자 유형 선택
- 체중 입력
- 총 카페인 자동 계산
- 권장 섭취량 계산
- 초과 여부 표시
- 진행률 바 시각화

## 🧠 카페인 기준
- 성인: 400mg
- 임산부: 200mg
- 청소년: 체중 × 2.5mg
- 50kg 미만 성인: 300mg

## 📁 프로젝트 구조
index.html - 화면 구조  
style.css - 디자인  
data.js - 음료 데이터  
script.js - 로직  

## 🚀 실행 방법
1. 레포 클론  
git clone https://github.com/SmallCogwheel/-_-

2. index.html을 브라우저로 실행

## 💡 동작 방식
- 음료 선택 → 용량 자동 변경  
- 카페인 계산 → 음료 카페인 × 개수  
- 권장량 비교 → 사용자 조건 기반 계산  
- 진행 바 → 섭취 비율 시각화
