# ☕ 카페인 계산기

사용자의 음료 섭취량과 체중을 기반으로 **카페인 섭취량과 권장량 대비 비율**을 계산해주는 웹 애플리케이션입니다.

---

## 📌 기능

- 음료 종류 선택
- 용량(ml) 선택
- 섭취 개수 입력
- 사용자 유형 선택 (성인 / 청소년 / 임산부)
- 체중 기반 권장 카페인 계산
- 카페인 섭취량 시각화 (퍼센트 게이지)
- 권장량 초과 여부 표시

---

## 🧠 계산 로직

- 기본 성인 기준: **400mg**
- 임산부: **200mg**
- 청소년: `체중 × 2.5mg`
- 체중 50kg 미만 성인: **300mg**
